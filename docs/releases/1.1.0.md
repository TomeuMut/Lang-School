# Lang School 1.1.0

## Changes

- Public registration with email, name, surname, birth date, password and password confirmation.
- Email/password sign-in and existing password recovery.
- Private user profiles created atomically with Supabase Auth accounts.
- Daily practice chart for the last 14 days, filtered by language and level, with an accessible objective-answer accuracy table.
- Nuxt security updates and the patched Node.js 22 runtime requirement already integrated in develop.

## Validation

All 22 automated tests, Nuxt type checks and the production build passed on the feature code using Node.js 22.23.4. The integration merge preserves that source tree. Browser verification and live service checks remain pending.

## Deployment requirements

Publishing this release does not provision a database. Apply `supabase/migrations/202610250001_user_profiles.sql` after the existing progress migration, enable email registration and confirmation, and configure the public Supabase URL and publishable key in Vercel. Verify confirmation email delivery, registration, sign-in, profile isolation and cloud progress against the actual project before considering account setup complete. See [account setup](../account-setup.md).

Without Supabase configuration the application continues in browser-local mode. Vercel deployment success and production runtime configuration must be verified separately.

## Git Flow

Prepare on `release/1.1.0`, merge into `main` with a merge commit, create the annotated `v1.1.0` tag, and merge production back into `develop`. Publish through SSH using normal pushes, without rewriting shared history. This release uses the explicitly authorized local merge workflow, as used in Portfolio.
