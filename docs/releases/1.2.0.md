# Lang School 1.2.0

## Practice expansion

- Five rotating tests of ten activities per skill, language and A1-C2 level: 240 tests and 2,400 scoped activity records.
- Grammar/vocabulary, reading, writing and speaking all use ten activities per test.
- Starting another practice selects an untouched test first; after all five, the least recently opened test returns.
- The result screen's **Hacer otro test** keeps the completed skill, and sessions restore their position and answers after reload.
- The 72 legacy starter IDs remain readable for existing history and saved drafts; new sessions use the expanded bank.
- GitHub Actions validates lint, types, unit tests, production build and desktop/mobile Chromium smoke tests.

## Content limitations

Reading texts/questions are shared within the adjacent A1-A2, B1-B2 and C1-C2 learning bands. Writing/speaking tasks share a scenario within each test while exercising different communicative purposes. The content and level assignments await teacher review; this is not an official exam simulator. Writing and speaking remain self-assessed.

## Validation

The feature commit passed GitHub Actions **Quality** and **Build and smoke**, as well as local lint, TypeScript, 29 unit tests and four desktop/mobile browser smoke tests. Smoke coverage includes a complete ten-question grammar session, reload at question seven, retained history and transition to test two. Screenshots were inspected at desktop and mobile sizes.

The production build succeeds with a client-chunk warning (approximately 579 kB minified, 189 kB gzip for the expanded inline bank). See [bank documentation](../practice-bank.md) for selection, compatibility and authoring details, and [CI/CD](../ci-cd.md) for deployment guarantees.

## Deployment

No database migration or secret change is required. Existing Supabase public configuration remains in place. Publish through `release/1.2.0`, merge to `main`, annotate `v1.2.0` and synchronize `develop`. Verify the Vercel deployment and Actions results for the production merge separately.
